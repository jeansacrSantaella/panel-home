      Toda tu casa bajo un mismo cielo.

      Panel unificado del hogar: cámaras en vivo, capturas del detector, mapa de la red, caídas de internet, calidad por equipo, almacenamiento, estado del servidor y una línea de tiempo con avisos. Su imagen son las Pléyades (M45); Alcyone, la más brillante, es la casa.

        Repositorio en GitHub ↗

        Todo el servidor usa solo la librería estándar de Python y la interfaz no depende de ningún framework.

        Servidor · Python 3, solo librería estándar

        • http.serverservidor web y API JSON con hilos (ThreadingHTTPServer)
        • sqlite3eventos, consumo, cuentas y sesiones en una base local (modo WAL)
        • urllibconsulta NetWatch, gestorCamaras, Telegram y ntfy
        • threadingrecolector en segundo plano cada 15 s
        • hashlib · hmac · secretscontraseñas PBKDF2-SHA256 y tokens de sesión
        • http.cookiescookie de sesión HttpOnly y SameSite=Strict
        • socket · http.clientAPI de Docker por socket UNIX (solo lectura)
        • /proc · /sysCPU, memoria, carga y temperatura del servidor
        • subprocesslectura opcional de consumo (CONSUMO_CMD)

        Interfaz · sin frameworks ni dependencias

        • HTML5estructura semántica, <dialog>, pestañas con hash
        • CSSvariables, grid, color-mix, backdrop-filter, tema claro/oscuro, movimiento reducido
        • JavaScriptvanilla: fetch, async/await, CustomEvent, ResizeObserver, Notification API
        • SVGlogos, íconos y la animación de las Pléyades

        Gráficas

        • hchart.jslibrería propia solo con HTML y CSS: barras, columnas, cintas, dona, chispa y mapa radial
        • hchart-calor.jsmapa de calor de movimiento por día y hora

        Servicios conectados

        • NetWatchproyecto propio: red, disponibilidad, latencia y equipos
        • gestorCamarasproyecto propio (FastAPI): cámaras, salud, capturas, clips y espacio
        • DetectorYOLO (Ultralytics) con PyTorch y OpenCV, dentro de gestorCamaras
        • go2rtcvideo en vivo de las cámaras por MSE
        • Docker Engine APIestado de los contenedores
        • Telegram Bot API · ntfyavisos al celular

        Despliegue

        • Dockerimagen python:3.12-slim con tzdata
        • Docker Composereinicio automático, healthcheck, volumen data/ y socket de solo lectura
        • Windows + WSL 2servidor Lenovo de la casa

        Seguridad

        • PBKDF2-SHA256200 000 iteraciones y sal aleatoria por contraseña
        • Sesionestoken aleatorio; en la base solo vive su hash
        • Proteccionesbloqueo por IP, POST solo JSON del mismo origen, cabeceras nosniff y DENY

        Desarrollo

        • unittestpruebas automáticas del servidor, eventos, capturas y seguridad
        • Claude + GeminiClaude planea y revisa; Gemini/Gemma ejecutan micro tareas
        • Bitácoracada paso documentado en docs/BITACORA.md
